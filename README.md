# iss

Когда МКС пролетит над Москвой так, что её видно глазами.

Берёт орбиту с CelesTrak, считает положение станции по SGP4 на 14 дней
вперёд и оставляет пролёты, где станция выше 10°, у наблюдателя сумерки
(солнце ниже -6°), а сама станция освещена солнцем.

```
git clone --recursive https://github.com/FullstackDepression/iss
cd iss
./run.sh
```

Нужны cmake, компилятор с C++17 и curl.

```
 Дата   Время  Откуда → Куда   Выше всего
 Дата   Время  Откуда → Куда   Выше всего
 21.10  06:00   ЮЗ → В        36°
 22.10  05:12   ЮЗ → В        31°
```

Орбиты считает [dnwrnr/sgp4](https://github.com/dnwrnr/sgp4) (Apache-2.0).
